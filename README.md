# moon-craters
Some preliminary programs from my work for Rhode Island Space Grant in Summer 2025. I'm working to get some more of my code from this summer up here. I also included a list of equations I used to validate simulation data. I mainly looked at ejecta thickness, depth to diameter ratio, and simple to complex crater transition. 

Sources for equations:
Melosh, H. J. (2011). Planetary surface processes (Vol. 13). Cambridge University Press.
Maxwell, D. E. (1977). Simple Z model for cratering, ejection, and the overturned flap. In Impact and explosion cratering: Planetary and terrestrial implications (pp. 1003-1008).
